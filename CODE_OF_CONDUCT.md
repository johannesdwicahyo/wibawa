# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text applies here as if it were written on this page.

In short: be respectful, assume good intent, accept criticism of your work without taking it as criticism of you, and keep discussion about the project. Harassment, insults, sexualized language or imagery, and publishing someone's private information are not acceptable in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour breaks this code, report it to the maintainer privately through [their GitHub profile](https://github.com/johannesdwicahyo), or use GitHub's "Report content" option on the comment or issue itself. Reports are kept confidential.

The maintainer will review each report and respond with a correction, a warning, a temporary ban or a permanent ban, following the enforcement guidelines of the Contributor Covenant.
